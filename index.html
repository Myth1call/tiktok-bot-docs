Twitch to TikTok Bot

Personal automation tool for a single account owner. It downloads Twitch clips, converts them to vertical 9:16 video, and publishes them to the owner's TikTok account using the official TikTok Content Posting API.

This is not a public multi-user service. Only the account owner runs the software on their own computer.
